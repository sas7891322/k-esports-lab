K Esports Lab v2.5
==================

1. 新增焦點賽事預告模式
   - K Premium 賽事可先建立預告，不公開任何分析內容、不開放購買。
   - 前台顯示「焦點賽事預告」與賽事提醒按鈕。

2. 新增瀏覽器 Web Push 賽事提醒
   - 使用者可針對單場焦點賽事設定/取消提醒。
   - 管理員把「分析內容已發布」由未發布切到已發布並儲存時，自動通知訂閱者。
   - 使用既有 /api/matches 與 /api/admin-matches，不增加 Function 數量。

3. 修復後台日期/時間操作
   - 電腦版新增清楚的「選日期」「選時間」按鈕，並強化原生 picker 圖示可視度。
   - 手機版預定時間恢復為：時 00～23、分 00 / 30。

4. 預告模式安全保護
   - 分析未發布時，後端不公開 preview / recommendation / prediction。
   - 綠界 create-order 也拒絕未發布焦點賽事建立訂單。

5. PWA / Service Worker
   - 新增 manifest.webmanifest、sw.js 與 192/512 圖示，支援瀏覽器推播流程。
